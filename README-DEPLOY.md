# 手机版部署说明

手机版是纯静态 PWA，不需要云服务器，也不需要数据库。

## 最简部署方式：Netlify Drop

1. 在电脑浏览器打开：

```text
https://app.netlify.com/drop
```

2. 把本目录整个拖进网页。

3. 网站会自动生成一个网址，例如：

```text
https://xxxx.netlify.app
```

4. 用 iPhone Safari 打开这个网址。

## 添加为手机 App

1. 在 iPhone Safari 打开部署后的网址。
2. 点击底部“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后可以从主屏幕直接打开。

## 首次使用 OCR

第一次上传截图时，软件需要下载中文识别模型，请保持手机联网。之后模型会缓存，速度会更快。

## 数据说明

所有店铺、截图和识别文本都保存在 iPhone 浏览器本地，不会上传到服务器。

清理 Safari 网站数据会导致本地记录被清除，请注意不要清理这个网站的浏览器数据。
